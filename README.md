# Copyright Infringement Checker
> 영상·음원의 저작권 침해 구간을 자동으로 탐지하는 데스크톱 도구

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey)]()

---

## 개요

영상이나 음원 파일 두 개를 비교해, **저작권 보유 영상의 오디오가 의심 영상에 무단으로 사용된 구간을 초 단위로 탐지**합니다.

- **단 2초짜리 클립**도 탐지 가능
- 배경음악이 덧씌워진 상태에서도 탐지
- 볼륨·EQ 차이에 강인한 창별(window-level) 정규화
- 우연한 유사도를 걸러내는 **오프셋 일관성 검증**
- 여러 쌍을 한 번에 **동시 분석** 지원

---

## 시작하기

### Step 1 — 프로그램 다운로드

1. GitHub 페이지 (https://github.com/Jinho-Jeong12/copyright_infringement_checker) 오른쪽 상단의 **`<> Code`** 버튼 클릭
2. **`Download ZIP`** 클릭하여 ZIP 파일 다운로드
3. 다운로드된 ZIP 파일을 **원하는 폴더에 압축 해제**
   - Windows: ZIP 파일 우클릭 → `모두 추출`
   - macOS: ZIP 파일 더블클릭
4. 압축 해제된 폴더 안에 `detect_copyright_6.py` 파일이 있는지 확인

---

### Step 2 — Python 설치

[python.org](https://www.python.org/downloads/) 에서 **Python 3.8 이상** 다운로드 후 설치

> **Windows 주의:** 설치 화면 하단의 **"Add Python to PATH"** 를 반드시 체크하고 설치하세요.

---

### Step 3 — 프로그램 실행 (Windows)

압축 해제된 폴더에서 **`detect_copyright_6.py`** 파일을 **더블클릭**합니다.

처음 실행 시 필요한 패키지(librosa, numpy, scipy 등)와 ffmpeg를 **자동으로 설치**합니다.
인터넷이 연결된 상태에서 실행하세요. 설치가 완료되면 프로그램 화면이 열립니다.

> ffmpeg 자동 설치가 실패할 경우 터미널에서 아래 명령을 실행하세요.
> ```
> winget install Gyan.FFmpeg
> ```

---

### Step 3 — 프로그램 실행 (macOS)

macOS에서는 `.py` 파일을 더블클릭해도 바로 실행되지 않을 수 있습니다. 아래 방법을 따르세요.

1. **`detect_copyright_6.py`** 파일을 **우클릭** (트랙패드: 두 손가락 클릭)
2. **"다음으로 열기"** → **"IDLE"** 을 선택합니다.
3. IDLE 창이 열리면 상단 메뉴에서 **Run → Run Module** 을 클릭합니다. (단축키: `F5`)
4. 처음 실행 시 필요한 패키지와 ffmpeg를 자동으로 설치합니다. 설치가 완료되면 프로그램 화면이 열립니다.

> ffmpeg 자동 설치가 실패할 경우 터미널에서 아래 명령을 실행하세요.
> ```
> brew install ffmpeg
> ```
> Homebrew가 없다면 먼저 [brew.sh](https://brew.sh) 에서 설치하세요.

## 사용 방법

### Step 4 — 비교 쌍 추가

1. 프로그램 상단 **`+ 쌍 추가`** 버튼 클릭
2. 행이 생기면:
   - **`저작권 영상`** 버튼 → 저작권을 보유한 원본 영상 선택
   - **`의심 영상`** 버튼 → 무단 사용이 의심되는 영상 선택
3. 여러 쌍을 추가하면 **동시에** 모두 분석

> 지원 형식: `.mp4` `.mov` `.avi` `.mkv` `.mp3` `.wav`
>
> 행 우측의 `X` 버튼으로 해당 쌍을 삭제할 수 있습니다.

---

### Step 5 — 옵션 설정

| 옵션 | 설명 |
|------|------|
| **유사도 임계값** | 기본값 **0.45** 권장. 낮출수록 민감(오탐↑), 높일수록 정밀(미탐↑) |
| **영상 2차 검증** | 영상 프레임까지 비교. 정확도↑ 속도↓. 다중 쌍 분석 시 해제 권장 |

---

### Step 6 — 분석 시작 및 결과 확인

**`전체 동시 분석 시작`** 버튼 클릭

각 행에서 진행 상황이 실시간으로 표시됩니다:

| 상태 표시 | 의미 |
|-----------|------|
| 대기 | 분석 대기 중 |
| 오디오 추출 | 영상에서 오디오 추출 중 |
| 특징 추출 | MFCC + Chroma 오디오 특징 추출 중 |
| 탐색 중 | 유사 구간 탐색 중 (가장 오래 걸림) |
| 없음 | 침해 의심 구간 없음 |
| N개 발견 | N개의 침해 의심 구간 발견 |
| 오류 | 오류 발생 (결과 로그 확인) |

분석이 완료되면 화면 하단 결과 로그에 구간이 표시되고,
의심 영상과 같은 폴더에 **`result_날짜시간.txt`** 파일로 자동 저장됩니다.

**결과 로그 예시:**
```
----------------------------------------------------------------
  [의심영상파일명]  --  2개 침해 의심 구간
----------------------------------------------------------------
  [1] 비교본  00:02:13.40 ~ 00:02:19.80  (6.4초)
       원본   00:00:05.00 ~ 00:00:11.40
       유사도: 0.82

  [2] 비교본  00:08:45.10 ~ 00:08:48.30  (3.2초)
       원본   00:00:05.00 ~ 00:00:08.20
       유사도: 0.76
  저장: C:\...\result_20240527_153012.txt
```

---

## 결과 해석

| 항목 | 설명 |
|------|------|
| **비교본 구간** | 의심 영상에서 침해가 발생한 시작~끝 시간 |
| **원본 구간** | 원본 영상에서 도용된 부분의 시작~끝 시간 |
| **유사도** | 1.00 = 완전 동일 / 0.45 = 탐지 하한선 |

> 이 결과는 **1차 스크리닝**용입니다. 최종 판단은 반드시 사람이 직접 확인하세요.

## 자주 묻는 질문

**Q. 침해 구간이 하나도 안 나와요.**
유사도 임계값을 낮춰보세요 (0.45 → 0.40). 원본과 의심 영상 파일이 올바르게 선택됐는지도 확인하세요.

**Q. 관계없는 구간이 침해로 나와요.**
유사도 임계값을 높여보세요 (0.45 → 0.55 이상).

**Q. ffmpeg 오류가 납니다.**
ffmpeg가 설치되지 않은 경우입니다. Step 3의 수동 설치 방법을 따르세요.

**Q. 분석 시간이 얼마나 걸리나요?**

| 영상 길이 (쌍당) | 예상 소요 시간 |
|-----------------|---------------|
| 5분 | 약 30초 ~ 1분 |
| 30분 | 약 3 ~ 7분 |
| 1시간 | 약 7 ~ 15분 |

## 작동 원리

```
영상 파일
   |
   v  ffmpeg (오디오만 추출)
WAV (11025 Hz, 모노)
   |
   v  5분 단위 청크 처리
MFCC(20) + Chroma(12) 특징 행렬
   |
   v  창(1초) 단위 슬라이딩 (0.25초 간격)
   |  + 창별 z-score 정규화
   |  + numpy 행렬 연산으로 NCC 계산
   |
   v  오프셋 일관성 검증
    · offset = 의심본시간 - 원본시간
    · 진짜 사용: 연속된 창이 모두 같은 offset -> 클러스터 형성
    · 우연 일치: offset 제각각 -> 자동 탈락
    · 단조성 검증 (Pearson 상관 >= 0.5)
    · 연속성 검증 (창 간격 <= 2초)
   |
   v
침해 의심 구간 목록 + 결과 파일 저장
```

## 주의사항

- 이 도구는 **1차 스크리닝 보조 도구**이며, 법적 효력을 갖는 공식 증거 자료가 아닙니다.
- 탐지된 구간은 반드시 **사람이 직접 청취·확인**한 후 활용하시기 바랍니다.
- 극도로 가공된 음원(속도 변경 ±10% 초과, 피치 2반음 이상 변경 등)은 탐지율이 낮아질 수 있습니다.
