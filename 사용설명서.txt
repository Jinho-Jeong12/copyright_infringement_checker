# 저작권 침해 구간 탐지기 — 사용설명서
작성일: 2026-05-27

================================================================================
  개요
================================================================================

영상이나 음원 파일 두 개를 비교해,
저작권 보유 영상의 오디오가 의심 영상에 무단으로 사용된 구간을
초 단위로 자동 탐지하는 프로그램입니다.

주요 특징:
  - 단 2초짜리 클립도 탐지 가능
  - 배경음악이 덧씌워진 경우에도 탐지
  - 볼륨·EQ 차이에 강인한 창별 정규화 적용
  - 우연한 유사도를 자동으로 걸러내는 오프셋 일관성 검증
  - 여러 쌍을 한 번에 동시 분석 가능


================================================================================
  설치 방법
================================================================================

1. Python 설치
   - https://www.python.org/downloads/ 에서 Python 3.8 이상 다운로드
   - Windows: 설치 시 반드시 "Add Python to PATH" 체크

2. 프로그램 실행
   - detect_copyright_6.py 파일을 더블클릭
   - 처음 실행 시 필요한 패키지(librosa, numpy, scipy 등)와
     ffmpeg를 자동으로 설치합니다. (인터넷 연결 필요)

3. ffmpeg 자동 설치 실패 시 수동 설치
   - Windows : winget install Gyan.FFmpeg
               또는 https://ffmpeg.org 에서 다운로드 후 PATH 등록
   - macOS   : brew install ffmpeg
   - Linux   : sudo apt install ffmpeg

================================================================================
  사용 방법 (단계별)
================================================================================

─────────────────────────────────────────
  Step 1. 비교 쌍 추가
─────────────────────────────────────────

  1) 상단 [ ＋ 쌍 추가 ] 버튼 클릭
     → 새 행이 추가됩니다.

  2) 행에서:
     · [저작권 영상] 버튼 클릭
       → 저작권을 보유한 원본 영상 파일 선택
         (예: 내가 제작한 영상, 저작권자가 소유한 영상)

     · [의심 영상] 버튼 클릭
       → 무단 사용이 의심되는 영상 파일 선택
         (예: 유튜브에서 발견한 의심 영상을 로컬에 저장한 것)

  3) 여러 쌍을 분석하려면 쌍 추가를 반복
     → 모든 쌍이 동시에 분석됩니다.

  지원 파일 형식: .mp4  .mov  .avi  .mkv  .mp3  .wav

  ※ 원본과 비교본 중 하나라도 비어있는 행은 분석에서 자동으로 제외됩니다.
  ※ 행 우측의 [ ✕ ] 버튼으로 해당 쌍을 삭제할 수 있습니다.


─────────────────────────────────────────
  Step 2. 옵션 설정
─────────────────────────────────────────

  [유사도 임계값]
  · 기본값 0.45 권장
  · 낮출수록 (0.35 방향): 더 민감하게 탐지 → 오탐(거짓 양성) 증가 가능
  · 높일수록 (0.85 방향): 더 엄격하게 탐지 → 미탐(실제 침해 놓침) 가능
  · 판단이 서지 않으면 0.45에서 시작해 결과를 보며 조정

  [영상 2차 검증 포함]
  · 체크 시: 오디오 탐지 후 해당 구간의 영상 프레임도 비교
             → 정확도 향상, 속도 느림
  · 체크 해제 시: 오디오만 비교 → 속도 빠름
  · 여러 쌍을 동시에 분석할 때는 해제 권장 (메모리 절약)


─────────────────────────────────────────
  Step 3. 분석 시작
─────────────────────────────────────────

  [ ▶ 전체 동시 분석 시작 ] 버튼 클릭
  → 파일이 지정된 모든 쌍이 동시에 분석을 시작합니다.

  각 행의 진행 상태:
  ┌────────────┬───────────────────────────────────────┐
  │ ⏳ 대기    │ 분석 시작 전 대기 중                  │
  │ 🔄 오디오  │ 영상에서 오디오 추출 중 (ffmpeg)      │
  │ 🔄 특징 추출│ MFCC + Chroma 오디오 특징 계산 중    │
  │ 🔄 탐색 중 │ 유사 구간 탐색 중 (가장 오래 걸림)    │
  │ 🔄 영상 검증│ 영상 프레임 비교 중 (2차 검증 시)    │
  │ ✅ 없음    │ 침해 의심 구간 없음                   │
  │ ⚠ N개     │ N개의 침해 의심 구간 발견             │
  │ ❌ 오류    │ 오류 발생 (결과 로그 확인)            │
  └────────────┴───────────────────────────────────────┘

  상단 카운터: "2 / 3 완료" 형태로 전체 진행 상황 표시


─────────────────────────────────────────
  Step 4. 결과 확인
─────────────────────────────────────────

  [화면 결과 로그 예시]

  ────────────────────────────────────────────────────────────────

  ────────────────────────────────────────────────────────────────
    [1] 비교본  00:02:13.40 ~ 00:02:19.80  (6.4초)
         원본   00:00:05.00 ~ 00:00:11.40
         유사도: 0.82

    [2] 비교본  00:08:45.10 ~ 00:08:48.30  (3.2초)
         원본   00:00:05.00 ~ 00:00:08.20
         유사도: 0.76
    📄 저장: C:\Users\...\result_20260527_153012.txt

  [결과 읽는 법]
  · 비교본 구간: 의심 영상에서 침해가 발생한 시작~끝 시간
  · 원본 구간  : 원본 영상에서 무단으로 사용된 부분의 시작~끝 시간
  · 유사도     : 1.00 = 완전 동일 / 0.45 = 탐지 하한선

  [결과 파일 자동 저장]
  · 의심 영상과 같은 폴더에 result_날짜시간.txt 로 자동 저장

================================================================================
  자주 묻는 질문 (FAQ)
================================================================================

Q. 침해 구간이 하나도 안 나와요.
A. 유사도 임계값을 낮춰보세요 (0.45 → 0.40).
   또는 원본과 비교본 파일이 올바르게 선택됐는지 확인하세요.

Q. 관계없는 구간이 침해로 나와요 (오탐).
A. 유사도 임계값을 높여보세요 (0.45 → 0.55 이상).

Q. ffmpeg 오류가 납니다.
A. ffmpeg가 설치되지 않은 경우입니다.
   터미널/명령프롬프트에서 아래 명령을 실행하세요:
   · Windows: winget install Gyan.FFmpeg
   · macOS  : brew install ffmpeg
   · Linux  : sudo apt install ffmpeg

Q. 극도로 가공된 음원도 탐지되나요?
A. 속도 변경 ±10% 초과, 피치 2반음 이상 변경 등
   극단적으로 가공된 경우 탐지율이 낮아질 수 있습니다.

Q. 영상 화면은 비교하지 않나요?
A. 기본적으로 오디오만 비교합니다.
   "영상 2차 검증" 옵션을 체크하면 영상 프레임도 추가 비교합니다.
